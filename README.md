## 🚀 Tecnologias Utilizadas

🔧 Back-end:
- ☕ **Java 17**
- 🌱 **Spring Boot**
- 🧰 **Maven**
- 🌿 **Hibernate (JPA)**

🛢️ Banco de Dados:
- 🐬 **MySQL**

🛡️ Segurança:
- 🔐 **Autenticação JWT**

🧪 Testes:
- 🧪 **JUnit 5**

## 📸 Funcionalidades

✔️ Cadastro e login de usuários com autenticação JWT  
✔️ Criação, edição e exclusão de postagens  
✔️ Criação, edição e exclusão de temas

✔️ Associação de postagens a temas  
✔️ Validação de permissões para ações específicas

## 💻 Como rodar o projeto

### ✅ Pré-requisitos

- Java 17 instalado ☕  
- Maven instalado 🧰  
- MySQL em execução na porta padrão (3306) 🐬  

### ▶️ Executando localmente

```bash
# Clone o repositório
git clone https://github.com/RibeiroCaroline/ProjetoBlogPessoal.git

# Acesse a pasta do projeto
cd ProjetoBlogPessoal

# Compile e rode o projeto
mvn spring-boot:run
```
Acesse o sistema no navegador:  
👉 [http://localhost:8080](http://localhost:8080)
